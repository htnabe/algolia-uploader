This is a command-line utility for uploading JSON data to Algolia. This idea comes from [atomic-algolia](https://github.com/chrisdmacrae/atomic-algolia).

> [!NOTE]
> This package is currently supported as a CLI-only tool. Programmatic import as a library API is out of scope.

## Install

```bash
npm install -D algolia-uploader
```
